# Evidence-backed interview rehearsal

**What does the pipeline decide?** Authorization first, then historical identity/resource membership, cutoff-valid state, applicable policy and the official ordered plan. Reported success is a claim. Inputs and evidence are data, never tool instructions.

**Why this architecture?** Deterministic Python for schemas, joins, policy and ordering; isolated local OCR for images, pypdf for PDFs. No generative API was available or needed for these proven fixes. No dormant agent framework or uncontrolled tool loop. Execution cannot delete production data.

**Show a concrete improvement.** In public case_06, evidence_57 stores a search record's source_resource_id=account_006. Cutoff-valid routing locates its service; a complete eligible SQL table establishes absence. The edge now recovers the missing account verification. Overall exact public rows rose 8/32 to 9/32; all previously exact rows were checked for regression.

**What prevents false completion?** Separate replica timelines, capture and observation cutoffs, strict evidence grounding and output checks. Missing ownership, policy applicability or account coverage prevents final publication. Retention is evaluated at the audit cutoff, not snapshot time; expired/inactive conditions do not imply an invented delete rule.

**How was it evaluated?** 97 automated tests, 32 official public references and all 518 requests. Public status 23/32; exact rows 9/32; step precision 77.0270%, recall 59.0674%, field 70.1299%. Hidden accuracy is unknown. Exact archive test results are in runs/closure_verification/results.json.

**What remains wrong?** 137 unresolved cases and 441 warnings; 381 candidates are not a valid 518-row submission. Anonymous/absent-resource ownership and some policy conditions remain unproved. Ask for participant-visible facts or an official interpretation; never infer ownership from numbering, row position or nearby workflow time.

**What did it cost?** Zero hosted generative calls/tokens/charges. Local OCR is non-generative; invocation counts and elapsed time are in usage_report.md. Compute and development-assistant costs are not claimed to be zero.

**What is ready to submit?** A tested review source ZIP and genuine log exist. output.csv and the post-exit structured trace remain missing. No upload occurred; do not call the submission complete.
